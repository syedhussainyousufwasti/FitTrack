# FitTrack

A full-stack fitness tracking web app built with the MEAN stack (AngularJS, Node.js/Express, MongoDB).

## Features
- User registration with email verification, and JWT-based login
- Workout logging
- BMI tracking
- Fitness goals
- User profile and dashboard

## Tech Stack
- **Frontend:** AngularJS 1.8, HTML, CSS
- **Backend:** Node.js, Express, Mongoose (MongoDB)
- **Auth & email:** JSON Web Tokens, bcryptjs, Nodemailer

## Getting Started
1. Go to the backend folder and install dependencies:
   ```
   cd backend
   npm install
   ```
2. Copy `.env.example` to `.env` and fill in your own values (MongoDB URI, JWT secret, email credentials).
3. Start the server (runs on port 3000):
   ```
   node server.js
   ```
4. Serve the `frontend` folder with any static server and open it in your browser.
